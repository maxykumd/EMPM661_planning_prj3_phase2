## Part 01 – A\* Path Planning

### Description

Implements the A\* algorithm on a differential drive robot model (TurtleBot3 Waffle) in an 800×400 cm map. The planner uses 8 wheel RPM action pairs to simulate robot motion and outputs the optimal path as a JSON file for futher use in the ROS2 node.

### How to Run
**Step 0 — Clone from github:**
```bash
git clone https://github.com/maxykumd/EMPM661_planning_prj3_phase2.git prj3p2
cd ~/prj3p2
colcon build
source install/setup.bash
```


**Step 1 — Generate the Astar path:**
```bash
python scripts/astar.py
```

### Inputs (prompted at terminal)

| Prompt | Description | Example |
|--------|-------------|---------|
| `Clearance (mm):` | Extra clearance beyond robot radius | `10` |
| `Start x (cm):` | Start X position in cm | `50` |
| `Start y (cm):` | Start Y position in cm | `200` |
| `Start Theta (deg, multiple of 30):` | Starting heading angle | `0` |
| `Goal x (cm):` | Goal X position in cm | `750` |
| `Goal y (cm):` | Goal Y position in cm | `200` |
| `RPM1:` | First RPM value for action space | `50` |
| `RPM2:` | Second RPM value for action space | `100` |

### Example of a working run

```
Clearance (mm): 10
Start x (cm): 50
Start y (cm): 200
Start Theta (deg, multiple of 30): 0
Goal x (cm): 750
Goal y (cm): 200
RPM1: 50
RPM2: 100
```

### Outputs
- `map_output.png` — obstacle map show raw obstacles (red) and inflated zones (purple)
- `astar_result.png` — Map with explored nodes (green) and optimal path (blue)
- `path_output.json` — Path and action sequence exported for the ROS2 driver

## Part 02 – ROS2 TurtleBot3 for Gazebo

### Description

A ROS2 node that reads the `path_output.json` generated by Part 01 and drives the TurtleBot3 through the planned path by publishing `Twist` messages to the `/cmd_vel` topic. Odometry is subscribed from `/odom` to track robot position.

### Setup ROS2 environment

```bash
source /opt/ros/humble/setup.bash
colcon build
source install/setup.bash
```
## File Structure

```
prj3p2.../
├── launch/
│   ├── competition_world.launch.py
│   ├── empty_world.launch.py
│   ├── robot_state_publisher.launch.py
│   └── spawn_turtlebot3.launch.py
└── scripts/
    ├── astar.py           ← Part 01: A* planner
    ├── astardrive.py      ← Part 02: ROS2 driver node
    ├── path_output.json   ← generated by astar.py
    └── map_output.png     ← generated by astar.py
```
### How to Run
**Step 2 — Launch the Gazebo competition world:**

```bash
ros2 launch turtlebot3_project3 competition_world.launch.py
```
**Step 3 — Run the Astar driver node:**
```bash
cd ~/prj3p2/scripts
ros2 run turtlebot3_project3 astardrive.py
```
> Make sure `path_output.json` is in the `scripts/` folder before running the driver.
